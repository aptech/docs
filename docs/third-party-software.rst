Third-Party Software
====================

GAUSS includes software from other companies and projects. Their licenses ask
that their copyright notices and license terms come with every copy of GAUSS.

They are all in the file ``THIRD-PARTY-NOTICES.txt``: for each piece of
software, its license, its copyright notices and the text of its license. The
file is in the GAUSS installation folder, for example ``C:\gauss27`` on
Windows or your GAUSSHOME directory on Linux. On macOS, it is in the
``Contents/MacOS/ghome`` folder inside the GAUSS application. On Windows and
Linux, the license of the Intel Math Kernel Library, built into ``gla.dll``
and ``libgla.so``, is also in the file ``INTEL-MKL-LICENSE.txt`` in the
installation folder.
