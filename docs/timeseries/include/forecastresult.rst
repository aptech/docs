.. list-table::
   :widths: auto

   * - fc.forecasts
     - hxm matrix, point forecasts. hx1 for univariate (ARIMA), hxm for multivariate (VAR/BVAR).

   * - fc.se
     - hxm matrix, forecast standard errors. For :func:`varForecast`, the standard errors use the fit's selected residual covariance. They include future shocks only by default; ``coef_uncertainty=1`` adds approximate coefficient estimation uncertainty for a fit without trend or xreg. The setting is not stored in this result.

   * - fc.lower
     - hxm matrix, lower confidence or credible bound.

   * - fc.upper
     - hxm matrix, upper confidence or credible bound.

   * - fc.level
     - Scalar, confidence or credible level used (e.g., 0.95).

   * - fc.h
     - Scalar, forecast horizon.

   * - fc.m
     - Scalar, number of variables (1 for ARIMA).

   * - fc.var_names
     - Mx1 string array, variable names. Empty for univariate models.

   * - fc.levels
     - Vector of requested central masses. ARIMA and ETS may leave it empty.

   * - fc.bands
     - Array of band structures, one for each requested central mass, in ascending order. For a VAR forecast, the first band supplies *fc.lower*, *fc.upper* and *fc.level*.

   * - fc.xreg_future
     - Future user exogenous values as supplied. A VAR trend generated by ``trend=1`` is not included.
